# State

Version 1.0.2 adds a Windows x64 NSIS installer and public-facing documentation. Runtime preferences are separated from older source-run copies.

Verified on Windows 11 x64: all four existing test suites; installation; installed executable startup; real quota and local project records; image loading; window hide and reopen; clean application exit; desktop shortcut target. Installer includes MIT and Electron/Chromium notices. No author credentials or session logs are packaged.

The runtime requires an existing, logged-in Codex CLI. No real Plus account or clean Windows 10 machine has been tested. The installer is unsigned. Both quota windows and automatic updates are not implemented.
