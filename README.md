# Seiya_see_token · Codex 剩余用量小组件

一个自用的 Windows 桌面小工具：在右下角托盘直接显示 Codex 剩余额度的数字，点击数字打开小面板，查看额度、重置时间和本机项目的 Token 用量。适合下载源码后，用 Codex 修改成自己喜欢的样子。

这是作者已有工具的课堂源码版本，使用 Electron 运行。当前提供源码下载，尚未提供独立安装包。

## 能看到什么

- 托盘数字：当前读取到的 Codex 配额窗口剩余百分比。
- 小面板：剩余比例、已用比例、窗口长度、重置时间。
- 项目列表：从本机 Codex 日志汇总的项目 Token 用量。
- 收进托盘后继续刷新；右键托盘可以刷新或退出。

**剩余额度百分比与项目 Token 数是两个不同指标。** 当前版本读取官方返回的 `codex` 配额的 `primary` 窗口，面板会标出实际窗口长度；不保证所有账号都返回每周窗口，也不显示所有模型的全部额度。项目占比是本地统计，不能据此换算账号还剩多少 Token。当前没有“自动跟随正在查看的对话”功能。

## 下载

在本页点击绿色 **Code → Download ZIP**，解压到自己的课程项目文件夹，再在 Codex 中打开这个文件夹。不要直接在压缩包里运行，也不要把别人的账号文件复制进来。

## 第一次运行

需要 Windows、Node.js 22.12 或更高版本及其附带的 npm，以及本机可用并已登录的 Codex CLI。仅安装 Codex 桌面软件，并不保证这台电脑已经满足全部条件。

在 Codex 中打开解压后的项目，先发这句话：

> 我想运行这个用量小组件。先看看这台电脑还缺什么，已经装好的就直接用。缺的请用中文告诉我怎么准备，先不要安装。

看完检查结果，再根据实际情况接着说：

> 按刚才说的准备好，然后打开这个小组件给我看。需要我登录的地方停下来告诉我。

已有环境时，也可以在项目目录用终端运行：

```powershell
npm.cmd ci
npm.cmd start
```

首次安装会联网下载项目依赖和 Electron；下载失败时先检查网络和错误信息，不要重复安装整套开发环境。无需为当前源码安装 Rust 或 Visual Studio。

程序会先检查 `CODEX_CLI_PATH` 环境变量，再检查用户 Codex 配置中的同名路径，最后尝试本机 `OpenAI/Codex/bin` 下的安装目录。其他安装位置可能需要手动指定可执行文件：

```powershell
$env:CODEX_CLI_PATH = '替换成这台电脑实际的 codex.exe 完整路径'
npm.cmd start
```

让 Codex 帮你查找真实路径即可，不需要照抄老师电脑的路径。不把登录凭据填进源码。

## 日常使用

1. 找到 Windows 右下角的托盘数字。被折叠时先点向上箭头，再把图标拖到常显区域。
2. 点击数字打开或收起小面板；面板可拖动，也可置顶。
3. 点关闭按钮后选“收进托盘”，数字会继续更新；选“直接退出”才会结束程序。
4. 需要立即更新时点面板刷新按钮，或右键托盘选“立即刷新”。

额度默认每 60 秒查询一次；本地日志变化会触发项目统计更新。刷新频率和接口返回存在延迟，不能把它当成逐 Token 的实时计费器。

运行成功后，可执行 `npm.cmd run create-shortcut` 创建快捷方式。该操作会在桌面和当前项目目录写入快捷方式。“同时打开 Codex”的脚本依赖用户桌面存在 `Codex.lnk`；没有时请先自己打开 Codex，再单独启动小组件。

## 改成自己的样子

先确认原版能运行、能显示自己的数据，再逐项修改。例如：

> 把小面板改成浅蓝色，剩余额度的数字再大一点，其他功能先保留。改完打开给我看。

主要界面在 `src/index.html`，配色和排版在 `src/styles.css`，显示逻辑在 `src/renderer.js`，托盘和窗口行为在 `src/main.js`。不熟悉代码时直接描述希望看到的变化即可。

## 显示不出来时

| 现象 | 先检查什么 |
| --- | --- |
| `npm` 找不到 | Node.js/npm 是否已安装，新开的终端是否能识别 |
| 显示 `--` | Codex CLI 路径、登录状态、网络及账号是否返回支持的额度数据 |
| 显示“暂未更新” | 正在保留本次运行最近一次成功结果，查看刷新时间并稍后重试 |
| 项目列表为空 | 当前 Windows 用户是否存在本地 Codex 会话日志 |
| 找不到托盘数字 | Windows 托盘折叠区，以及程序是否已经退出 |

不要为了让界面出现数字而填入假数据。账号接口或日志格式变化后，可能需要更新代码。

## 数据与隐私

配额通过本机 Codex CLI 的 `account/rateLimits/read` 查询，查询可能需要联网并使用本机现有登录状态。项目统计读取当前用户 `.codex/sessions` 下的日志；源码没有把会话日志上传到本项目服务器的逻辑。窗口位置等偏好保存在 Electron 的用户数据目录。

仓库不包含作者的登录文件、会话记录、个人用量数据、已安装依赖或本机快捷方式。请勿将自己的 `.codex`、`auth.json`、日志、密钥和真实用量截图提交到公开仓库。
